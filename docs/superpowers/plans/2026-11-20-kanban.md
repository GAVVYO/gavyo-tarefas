# GAVYO Tarefas — implementação inicial

Servidor Node.js único para a interface web e o MCP. MySQL em hospedagem e SQLite para execução local. Ambos os canais usam as mesmas regras de tarefas e de acesso.

1. Criar persistência, contas e sessões. Verificar criação de usuários e isolamento do acesso.
2. Montar quadro, filtros, Minhas tarefas, arquivo e detalhes com checklist, comentários e histórico.
3. Registrar ferramentas MCP para consultar, criar, atribuir, mover e comentar. Validar reflexo das alterações na interface e autoria no histórico.
4. Verificar execução local, versionar o código no repositório privado e documentar a configuração para hospedagem.
